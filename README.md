# gpsfacil-instagram

Imágenes públicas para las publicaciones de Instagram de GPS Fácil (@gpsfacil), programadas con Metricool.

- `AAAA-MM/<pieza>/` — piezas listas para publicar (1080x1350, JPG).
- `assets/logos/` — logos (color, blanco para fondos oscuros) e íconos de las apps.
- `assets/apps/` — capturas oficiales de GF Service, GF Estética y GF Radar.
- `assets/fotos/` — fotos propias (Aconcagua, equipos).
- `tools/` — scripts de generación (HTML + Playwright).

Reglas de marca: Poppins, turquesa #1EBDBA, azul #0F2A33. No publicar el equipo instalado en Plaza de Mulas.
